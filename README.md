# Detection Engineering Lab

Hands-on Detection & Response Engineering laboratory focused on:

- Endpoint telemetry
- Cloud detection
- Identity detection
- Kubernetes security
- Detection-as-Code
- Security automation
- Incident investigation

## Objectives

The goal of this repository is to build practical Detection Engineering skills across:

1. Telemetry collection
2. Detection hypothesis development
3. Detection rule implementation
4. Detection testing
5. Alert enrichment
6. Incident investigation
7. Automated response

## Repository Structure

- `detections/`: detection rules
- `telemetry/`: sample/raw security events
- `automation/`: Python security tooling
- `attack-simulations/`: controlled attack scenarios
- `investigations/`: incident investigation reports
- `terraform/`: Infrastructure-as-Code
- `tests/`: automated tests
- `docs/`: technical documentation
